# MEAPER
Modular hybrid actuator design (NiTi, Robotics)
An attempt to solve infinite DoF problem of soft actuators by hardware descritization.
You can find more details about this project in attached MEAPER.pdf.
to run app.py with inverse kinematics simulation:
1. download locally directory or use git commands to clone it
2. install python dependencies from requirements with
   pip install -r requirements.txt
3. go to installed directory in terminal
4. run
   python app.py
